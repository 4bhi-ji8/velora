# Project Vision
## Velora 
Modern Fashion E-commerce Platform
## Goal
 Velora is a modern fashion e-commerce platform that allows customers to brows,search, purchase and manage fashion products online while providing administators with tools to manage products ,orders and customers.
 this project also being built to understand full-stack software engineering including front end development,backend development ,APIs, database,authentication and deployment.
## Target Users 
Customer
- browse products
- Purchase products
- Track orders

Administators
- Manage Products
- Manage Orders
- Manage customers
## Why im building this?
To gain practical experience in designing and developing a production-style e-commerce application while learning frontend development,backend development ,APIs, database,authentication and deployment.
